# Lab 9: Deploy Kubernetes Cluster Using Kubeadm

## Steps

1. Installed and configured containerd on the control plane and worker nodes.
2. Installed kubeadm, kubelet, and kubectl on both nodes.
3. Initialized the control plane using `kubeadm init`.
4. Configured kubectl using the admin configuration file.
5. Installed Calico CNI for pod networking.
6. Joined the worker node to the cluster using `kubeadm join`.
7. Verified that both nodes were in the `Ready` state.
8. Verified that all Kubernetes system pods were `Running`.
